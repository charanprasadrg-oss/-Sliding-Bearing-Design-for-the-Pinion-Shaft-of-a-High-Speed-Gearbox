This project implements a simplified hydrodynamic analysis of sliding bearings for the pinion shaft of a high‑speed turbo gearbox. The focus is on comparing three common bearing concepts—tilting‑pad (5‑pad), offset‑halves, and three‑lobe bearings—under realistic operating conditions using ISO VG 32 mineral oil.

The MATLAB script models a journal bearing using classical short‑bearing theory. For a specified load, shaft speed, journal radius, bearing length, and a range of relative clearances (C/R), the code estimates key performance metrics: minimum oil film thickness, lubricant flow rate, and frictional power loss. These quantities are directly related to bearing safety, thermal behavior, lubrication reliability, and overall efficiency.

To distinguish the behavior of the different bearing concepts without resorting to a full 3D thermo‑elastohydrodynamic solver, empirical correction factors are applied for each type. These factors reflect typical characteristics such as the better stability and higher losses of tilting‑pad bearings, the efficiency advantages of offset‑halves bearings, and the intermediate performance of three‑lobe bearings. The script then sweeps relative clearance values for all three designs and generates comparative plots of power loss, lubricant flow rate, and minimum film thickness versus clearance.

The results can be used to visualize trade‑offs between lubrication safety (sufficient film thickness), temperature control (through flow and power loss), and efficiency (minimized frictional losses). This supports engineering decisions when selecting the most suitable bearing type and clearance range for a given high‑speed gearbox application.

Overall, the code provides a compact, transparent tool for early‑stage bearing concept evaluation and for reproducing the trends shown in the project’s design and comparison slides.
